# The Operating System of a Business — portfolio assets

Public hosting for the talk deck and the figures used in the accompanying blog
post about **Syntell BizOps Intelligence** — a governed agentic platform built
across sales, engineering, manufacturing, stock, procurement and finance, on an
SAP ECC 6.0 system with no API.

- **`deck/`** — the 90-slide talk deck (Reveal.js vendored; runs offline).
  Press `S` for speaker notes, `Esc` for the slide overview.
- **`img/`** — the figures embedded in the blog post.

## About the screenshots

Every screenshot is the **live production system with real data on screen**. A
redaction layer is injected before capture and the capture is verified *after*
the screenshot as well as before, so what the check reports describes the file on
disk rather than the DOM a moment earlier. Blurred: all monetary values, customer
and supplier names, employee and operator identity, chart geometry, form values,
tenant identifiers, AI-generated prose, and the cells of model-rendered tables.

One image is deliberately left readable — the "it refuses" answer, where the
assistant declines to answer because its live tool calls timed out. Every visible
string in it was reviewed by hand.

No application source code is published here.
